clowder-bot 能做什么

挑一只猫，说句话，收结果。

clowder-bot 是在你自己电脑上运行的聊天软件。联系人是猫猫，可以单聊，也可以拉几只进一个群；回复由这台电脑上的 Claude Code、Codex 或其它模型写出，每只猫用哪一个，跟它的性格一样，是它自己带着的。

关于示例示例联系人里的对话是事先写好的，由一个脚本代替引擎回放；界面和适配层都是真的。装好的 clowder-bot 里，回复来自每只猫自己用的那个 Agent。示例假定这台电脑装着这个应用能接的三种 Agent（Claude Code、Codex、Kimi）；另外五只猫是照引擎里已有的猫摆进列表的，只为列表完整，不表示它们的 Agent 在这里跑过。

示例对话现在没在运行，下面的图照样能看。想点进对话里试：在项目目录运行 npm run showcase，打开它给出的 /tour/ 地址。

第一次打开

打开就能聊

第一次打开，它请你领一只猫猫回家：挑一只，起个名字。每只猫都带着自己的名字和性格，选中的那只在旁边有一张卡片：它坐在垫子上，写着它的品种、性格、擅长，和它用这台电脑上的哪个 Agent 思考：宪宪用 Claude Code，砚砚用 Codex，墨墨用 Kimi，别的猫用其它模型。这是猫自己带着的，不用另外选。

它要用的 Agent 这台电脑上没装、没登录或者暂不支持时，这只猫现在领不了：它排在后面，小一号，脚下一圈虚线；选中它，卡片上它的 Agent 标着「暂不支持」「未安装」或「未登录」，旁边一个「自定义」按钮，带着它的长相去自定义。「自定义」也是其中一个选项：长相从这些猫里挑，做什么、什么性格、用这台电脑上的哪个 Agent 都自己定。选几只猫猫就是一个群聊，群名可以不填。

怎么试点左栏上方的「＋」（新建），在弹窗里切换「猫猫」或「群聊」

打开 clowder-bot

在「宪宪」的对话里

回复是活的

发出去就看到它在输入。字一段一段写出来，标题、代码和表格当场排好；它去读文件、查资料时，下面有一行说它正在做什么。

随时能停，也能在它写的时候接着说：它接得住，就在同一条回复里一起回答，排在你这句下面；接不住，写完这条再另起一条回答。停下的回复会写明「已停止」。

这里的每只猫都像聊天一样说话：先说结论，通常几句话说完；要清单、表格、代码或长文时照给。这是默认的，不用设置。

怎么试点「看它现场演示」，写到一半时按输入框右边的停止键；或者趁它还在写再说一句，看它在同一条回复里接着回答

没做完也如实说

没写完的回复会说清楚：这次没完成、中途被打断，还是你停下的。可以看详情，也可以再发一次。

对话里暂时画不出来的内容，会写「还有 1 项内容暂时无法显示」，不会悄悄丢掉。

怎么试看它现场演示：先失败一次，点「再发一次」就成了

在「金哥」的对话里

找得到

⌘K（Windows 上是 Ctrl+K）搜猫猫、群聊和聊过的话，回车直接跳到那条消息；也能只在当前对话里找。它搜的是每个对话最近的消息，也会这样告诉你。⌥↑ / ⌥↓（Windows 上是 Alt+↑ / Alt+↓）切到侧栏里的上一个、下一个聊天。

往上翻会加载更早的消息，引用能跳回原话；新对话和历史对话在顶栏的 ⋯ 里。

怎么试打开对话后按 ⌘K，输入「纸页感」

打开这个对话

在「产品评审」群里

群聊

直接说，由一只猫猫接；@名字 叫某一只；输入 @ 还能选「全体」，把每只都叫上。不在群里的猫，会直说它没有回答。

群可以改名、加减成员、删除；每只猫有自己的颜色和脸。

怎么试点「看它现场演示」，三只猫各答一句；四只猫的「读书会」里还投过一次票

像平常用的聊天软件

联系人列表

最后一句和时间，最近聊的在上面；未读有数字，标签页的标题里也有；等你确认的写在行上，置顶的猫在最上面，没发出去的话各留各的。

资料页

点顶栏的名字：资料、文件、记忆、定时。用哪个 Agent、哪个模型，收在「高级」里，平时用不到。

通知

在设置里打开桌面通知：别的对话有了回复，或有事等你确认，就提醒你。正在看的对话不提醒，也没有声音。

底下是什么

引擎是 Clowder AI：规划、工具、记忆、定时和存储都由它负责。clowder-bot 是它上面的聊天界面和一层适配，不另做一套。回复由这台电脑上的 Claude Code、Codex 或其它模型写出，每只猫用它自己的那个。

  1. 你挑猫、说话、收结果
  2. clowder-bot聊天界面 · 适配层
  3. Clowder AI规划 · 工具 · 记忆 · 定时 · 存储
  4. Claude Code、Codex 或其它模型每只猫用它自己的那个，在这台电脑上，用你已经登录的账号

这一页和示例对话只在 npm run showcase 里有；图片都是界面本身的截图。
