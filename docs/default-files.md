# 默认文件与兼容范围

默认文件根目录沿用 `BOT_RUNTIME_DATA_DIR/workspace`，新单聊使用 `cats/<native-cat-id>`，新群聊使用 `groups/<UUID>`。目录由已有原生目录接口创建，普通聊天不要求创建项目或任务。旧项目元数据只读保留，已有会话、附件与交付物不迁移、不删除。

本次仅复用附件分支 `1893f70c` 的 Bot 文件与界面适配，没有导入该分支的宿主 Seatbelt 部署、L0 注入补丁 P007、任务历史补丁 P006。当前运行时启动策略保持原样；不能将目录组织或下载接口的路径检查宣称为所有 Agent 工具的操作系统隔离。

Bot 文件接口继续限制在当前原生会话的管理目录内，拒绝越界、符号链接、非普通文件和伪造来源；已存快照下载复核摘要。原生文件发布的读取按[适配契约](chat-experience-api.md)另行核对消息与来源。猫猫子目录不宣称互相独立的权限沙箱。

首批实现保留隔壁实例及其文件保护。后续经用户授权发布时，继续使用该实例的原有数据和保护规则，只更新 Bot 构建并补齐原生偏好读取所需的 Git／目录配置，见[当前实例发布记录](chat-files-collaboration-memory.md#当前实例发布与偏好读取修复)。现有上游补丁作为历史差异保留；本轮没有增加、扩大或移除补丁，后续统一按 [AGENTS.md](../AGENTS.md) 的上游纪律评估升级与迁移。
