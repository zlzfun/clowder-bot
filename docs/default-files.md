# 默认文件目录与原生协作

Clowder Bot 的日常操作围绕聊天、附件、交付物和原生任务展开。没有项目创建、项目切换或群聊项目选择。用户不必先创建任务或指定负责人；已有 Task 的负责人、进度、执行与传球结果由 Clowder AI 提供。

## 目录与兼容

默认文件根目录是 `BOT_RUNTIME_DATA_DIR/workspace`。新单聊使用 `cats/<native-cat-id>/`，新群聊自动使用独立的 `groups/<UUID>/`。这些子目录用于文件组织；它们不是每只猫之间独立的权限沙箱。群聊成员在该群的同一目录工作。

旧项目、文件、消息、任务和 Thread 不删除、不移动、不合并。当前打开的会话保持不变；旧项目会话和新的普通会话都可从猫猫详情的“历史对话”打开。新建对话回到该猫默认目录，并记录旧会话引用。历史切换只接受该猫已知的单聊 Thread；源或目标有执行/排队时拒绝，旧版本请求拒绝。

旧 `POST /projects`、`PUT /bots/:name/workspace` 和带 `projectId` 的新群聊返回 410。只读旧项目元数据保留作兼容，不再提供新项目产品流程。

## 文件保护的实际范围

本版在 macOS 上将**整个 Clowder AI 原生 API 宿主及其子进程**置于同一个 Seatbelt 文件边界内，覆盖模型内置文件工具、Shell、SDK 子进程和宿主内的原生工具。Agent 使用的权限模式不会解除宿主继承的操作系统限制。

- 业务文件只能写 Bot 管理目录；原生数据库、日志、会话与临时文件使用运行时数据目录。
- 原生 Agent 已有的会话、日志、协调锁目录，以及 Codex 已有状态 SQLite 文件及其日志伴随文件、安装标识，是列明的运行状态写入例外。临时文件重定向到 Bot 数据目录；不授予整个 HOME 或 Agent 配置目录写权限，也不创建第二套凭据库。
- 用户 HOME、外置卷及常见临时资料目录默认不可读取，运行代码、原生 Agent 配置/认证和执行所需路径除外。用户通过附件提供资料，或由宿主设置 `BOT_READ_ONLY_DIRS='["/absolute/source/directory"]'` 授予外部资料只读访问。
- macOS 原生 Claude 登录沿用系统钥匙串。经用户明确批准，仅增加 `~/Library/Keychains/login.keychain-db` 和 `~/Library/Preferences/com.apple.security.plist` 两个只读例外；不开放整个钥匙串目录，不导出、复制或另存凭据。
- 文件保护不等于网络权限控制，也不承诺远程应用或外部独立服务的写操作受到本地文件沙箱约束。
- macOS 的 `/bin/ps` 是 setuid 系统程序；唯一按固定系统路径豁免的进程是此只读查询工具，用于保留原生进程身份和生命周期核验。没有任意命令豁免。
- 不支持 Seatbelt 的平台拒绝启动，不能静默回落到全权限；Linux/Windows 的同等宿主边界尚未适配。

这是一条 Bot 应用级边界；不宣称猫猫子目录之间有强隔离。`workspace` 的界面隐藏与权限策略是两件独立的事。

## 外部资料与副本

只读资料可直接读取。需要修改时，原生部署指令要求先将必要材料复制成当前目录中的独立普通文件，记录来源、时间、内容摘要后修改副本。不得用软硬链接替代独立复制，不自动同步或覆盖原件。目录、代码仓和运行中数据库需按依赖/一致性处理，不能机械复制单个文件。未经允许的来源应请用户上传，而不是绕过读取限制。

操作系统负责拒绝越界写入；“被拒后如何复制、记录来源、说明结果”是 Agent 的工作流程，不是假装内核会自动拦截并改写所有写操作。当前不提供写回原件入口；成果在聊天中下载或由用户自行放回目标位置。

附件和交付物沿用 SHA256 清单、独立快照、按 Thread 授权、下载时复核、受限文本/图片预览。猫猫交接引用现有材料；需要编辑其他猫的材料时，默认生成自己的副本。

## 原生任务与传球

`ownerCatId`、`ownerRevision`、Task-backed handoff 是原生能力。一次普通 `@` 或咨询不由 Bot 自动解释成负责人变更。聊天仅展示已有原生任务及其负责人、真实执行状态和控制；“请求传球”只发请求，直到原生确认后才改变展示。

P006 仍只补记原生 Task 的成功负责人变化（认领、人工改派、正式交接），并和该次变化一并持久化。该历史不是所有球权事件的副本，也不是另一套调度器。保留历史来源类型，不把人工改派伪装成猫猫正式交接。

## 验证

- `npm test`：默认目录、历史会话、附件、交付物、原生任务和界面契约。
- `npm run test:file-guard`：真实操作系统测试越界覆盖/新建/删除/重命名、软硬链接、子进程写入被拒，以及独立副本可编辑且原件不变。
- `BOT_DEFAULT_FILES_ACCEPTANCE=1 PORT=3232 npm run test:default-files`：只用于独立候选；真实 Agent 在专用测试文件上验证写入拒绝及复制编辑。记录保存在 `.runtime/simplify-20261105/`，不删除既有数据。
